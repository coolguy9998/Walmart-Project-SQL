# Walmart-Project-SQL
Oracle SQL and Excel project analyzing Walmart financial statements for fiscal years 2024–2026.

## Project Overview

This project analyzes Walmart Inc.'s financial performance for fiscal years
2024 through 2026 using publicly available Form 10-K financial information.

The project combines accounting and information systems concepts by collecting
financial statement data in Microsoft Excel, storing the data in a relational
Oracle SQL database, validating financial relationships, and performing
financial analysis through SQL queries.

## Tools Used
- Oracle SQL
- Oracle FreeSQL / SQL Developer
- Microsoft Excel
- GitHub
- Walmart Form 10-K filings

## Database Tables

The relational database contains eight tables:

- Companies
- Fiscal Periods
- Income Statements
- Balance Sheets

- Segments
- Segment Results
- Data Sources

## Financial Analysis

The project evaluates:

- Revenue growth
- Operating margin
- Net profit margin
- Current ratio
- Quick ratio
- Operating cash flow
- Free cash flow
- Segment sales
- Segment operating income
- Segment operating margins

## Data Validation

Validation queries were created to confirm:

- Net sales plus membership and other income equals total revenues
- Operating income reconciles to revenue less cost of sales and operating expenses
- Beginning cash plus the change in cash equals ending cash
- Segment net sales reconcile to consolidated net sales
- Walmart shareholders' equity plus noncontrolling interest equals total equity

## Data Source

Financial data was collected from Walmart Inc. annual Forms 10-K for fiscal
years 2024 through 2026.

All financial amounts are presented in USD millions unless otherwise noted.
